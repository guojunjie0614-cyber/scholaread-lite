# ScholarLite app icon

Selected concept: 01, blue folded-paper S.

`app-mark.png` is the transparent S for the sidebar, without a white tile.
`app-icon.png` is the system icon master: a single full-bleed white background, with no smaller rounded tile embedded inside it. The current macOS system icon service supplies the rounded presentation of the bundled ICNS.
`ScholarLite.icns` is generated by `node scripts/create-mac-app.mjs` using macOS sips and iconutil.
On macOS, the Dock and About panel use the application bundle's native icon. Do not override them with `app.dock.setIcon(app-icon.png)` or a PNG About icon: those overrides bypass the system mask and show square corners. The PNG remains the page icon and the non-macOS application icon. The sidebar uses the transparent mark.

Packaging atomically refreshes the existing managed Desktop symlink after replacing the bundle, so Finder reloads the entry instead of retaining an earlier icon. Custom launchers and real applications on the Desktop are left untouched.

Created with the built-in imagegen tool from the approved comparison board, then edited to separate the transparent mark from the system icon. Previous production assets are retained in `.work/icon-original/`.
